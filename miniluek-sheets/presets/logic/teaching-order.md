# Teaching order of the logic lane

`logic.json` is English, `logik.json` is German: four ice-palace sheets. No plain sheet comes
before them. Each is the first sheet for its step, so each comes after the same idea with
objects. Start once the child can work a LÜK page with the number sheets: 12 numbered tasks, one
tile per task, pattern check at the end. Until the number sheets are mastered, they keep five
days a week; on the other two, a letters or a logic sheet is that day's sheet. Repeat a mastered
ice-palace sheet a week later.

| Sheet | First with objects | Practises |
|---|---|---|
| P1 necklaces | an ABAB bead string: "which comes next?" | continuing an AB pattern, the gap always last |
| P2 palace windows | shape blocks in other colours and sizes: "find the same shape" | the same shape in another colour and size |
| P3 winter party | three toy animals of one kind and one of another: "who does not belong?" | odd one out by kind |
| P4 castle maps | a toy on a 3 by 3 grid drawn on paper: "put yours in the same place" | the same place in a 3 by 3 grid |

The four sheets tell one story, a day in the ice palace, in the titles and the adult-read goal
lines. The necklace gap is always last and the odd guest always differs in kind; charms or
guests to tell apart differ in colour and outline. Pink stations sit left, blue right; the routine, the daily cap and the pattern check
are the numbers lane's ([teaching order](../numbers/teaching-order.md#using-the-sheets)).
