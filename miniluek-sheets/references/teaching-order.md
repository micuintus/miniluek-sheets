# Teaching order of the preset

| Sheet | Practises |
|---|---|
| S1 same thing, same number 1–3 | seeing 1–3 at a glance; the number stays when the arrangement changes |
| S2 princesses → cupcakes, frogs → crowns 1–6 | counting one by one, "how many" |
| S3 dice → hearts and stars 1–6 | dice patterns, checked by counting |
| S4 fingers and stars → dice 1–6 | finger patterns, shown on own fingers (index-first in this preset) |
| S5 who has more dots | comparing quantities, differences of 2 : 1 and more |
| S6 hearts and crowns → numbers | quantity to numeral |
| S7 numbers → dice | numeral to quantity |
| S8 scattered hearts and stars → numbers | counting an unordered set, each one once |
| S9 princess and frog path → numbers | position on a number path |
| S10 count the dots, who has more | comparing by counting, differences from 3 : 2 |
| S11 who has the bigger number | comparing numerals 1–6 |
| S12 treasure chest 3–8 (later) | five and more, 6 = 5 and 1 |
| S13 one more (later) | the number after |

## Why this order

Small sets, counting, patterns, comparing, numerals both ways, a number path, comparing again by
counting and with numerals, then part-whole and "one more": the progression of the What Works
Clearinghouse guide *Teaching Math to Young Children*, with patterns of four to six placed after
counting. Each step and each sheet mapped to its studies: [research](research.md).

## Design rules

- Each sheet runs one direction: no answer repeats a task picture, so the easiest wrong match
  is never an identical copy. Both directions of the quantity–numeral link get their own sheet.
- Two colour families per sheet: pink tasks have pink answers, blue tasks blue answers. The
  only other answer with the right number has the other colour.
- Tasks and answers use different layouts, so the child counts instead of matching shapes.

## Using the sheets

- Do the same idea with real objects first, then the sheet.
- Say what to look for, let the child touch-count and place, then turn the box and fix the
  wrong tiles together; redo a wrong task with objects. The routine follows the Focus/Plan,
  Act, Reflect method of MILE, a 1:1 math tutoring programme tested in randomised trials
  (Kable, Coles & Taddeo 2007; Coles, Kable & Taddeo 2009).
- One sheet per session, 5–10 minutes, stop before frustration; move on after two days with
  the pattern right first time, repeat a mastered sheet a week later.
- There is no study of miniLÜK itself; the sheets are practice with feedback, not instruction.
